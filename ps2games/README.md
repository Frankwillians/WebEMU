# Jogos de PlayStation 2 (experimental)

Coloque aqui seus ISOs/arquivos de PS2.

Formatos aceitos: `.iso`, `.chd`, `.cso`, `.isz`, `.bin`, `.img`, `.elf`, `.mds`.

A pasta pode ser trocada pela interface do launcher
(`http://SEU_IP:3000/play.html` → cartão **PS2**) ou pela variável de ambiente
`PS2_DIR`.

> **Aviso:** o emulador de PS2 no navegador (Play! .js) é **experimental**.
> A compatibilidade e a velocidade variam bastante entre jogos e ele não é
> recomendado para celulares. Não precisa de BIOS.
