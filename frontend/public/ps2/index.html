Play!.js

Emulador de PlayStation 2 em WebAssembly (Play!). É experimental: a compatibilidade e a velocidade variam muito e não é recomendado no celular.

Carregar ISO local: botão Escolher arquivo acima do canvas.

Controles (teclado):
Direcional: setas · Analógico L: F/H/T/G · Analógico R: J/L/I/K
□ = A · ✕ = Z · △ = S · ○ = X · Start = Enter · Select = Backspace
L1/L2/L3 = 1/2/3 · R1/R2/R3 = 8/9/0

Formatos: ISO, CSO, CHD, ISZ, BIN, ELF. Não precisa de BIOS.
